# Zyean — Architect & ArchViz portfolio

Bilingual (English / Deutsch) one-page portfolio. Plain HTML, no build step, free hosting on GitHub Pages.

## Edit
- **Projects:** `data.js` (taken from spaceverseltd.com). Images in `images/<project-id>/`.
- **CV:** put `cv.pdf` in the root; the contact button links to it.

## Publish (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → Branch `main`, folder `/ (root)` → Save.
The site appears at `https://abnzyean.github.io/<repo-name>/` within a minute or two.
